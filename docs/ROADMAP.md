# 로드맵 (마일스톤)

국내 주식(KRX) 자동 매매 프로그램. **가상 매매 → KIS 모의투자 → 실전 매매** 순으로 진화하며,
각 단계에서 웹개발과 주식 개념을 함께 학습한다.

> 상태 표기: ⬜ 예정 / 🟨 진행 중 / ✅ 완료

---

## M0. 프로젝트 기반 ✅

프로젝트의 뼈대와 운영 규칙을 만든다.

- [x] Next.js 스캐폴딩 (TypeScript + Tailwind CSS v4 + App Router)
- [x] 프로젝트 규칙 문서화 (AGENTS.md)
- [x] 마일스톤 수립 (이 문서)
- [x] 화면 버전 표기 (footer의 VersionBadge)
- [x] main 브랜치 정리 및 첫 PR

**학습 목표**
- 웹개발: Next.js App Router 구조(layout/page), 서버 컴포넌트, SemVer 버전 관리
- 주식: (없음 — 기반 단계)

---

## M1. 시세 조회 대시보드 ✅

실제 KRX 시세(지연/일봉)를 조회하고 보여주는 화면을 만든다.

- [x] 종목 검색 (종목명/종목코드)
- [x] 현재가(지연 시세)와 등락률 표시
- [x] 일봉 차트 표시
- [x] 관심 종목 목록 (localStorage)

**구현 메모**
- 시세는 공급자(provider) 인터페이스 뒤에 숨겼다 → `src/lib/market/`, 자세한 내용은
  [docs/market-data.md](./market-data.md)
- 기본은 API 키가 필요 없는 **목업 공급자**, `MARKET_DATA_PROVIDER=datagokr`로 공공데이터포털
  실제 시세 전환
- 관심 종목 DB 저장은 M2에서 다룬다

**학습 목표**
- 웹개발: 외부 API 연동(Route Handler), 데이터 페칭과 캐싱, 차트 라이브러리
  → [learning/web-server-client-components.md](./learning/web-server-client-components.md)
- 주식: 호가/현재가/등락률, 캔들(일봉)의 의미, 거래량
  → [learning/stock-price-basics.md](./learning/stock-price-basics.md)

---

## M2. 가상 계좌 & 수동 매매 🟨

가상 잔고로 직접 매수/매도해 보는 단계. 매매의 기본 개념을 몸으로 익힌다.

- [ ] 가상 계좌 생성 (초기 자본금 설정)
- [ ] 수동 매수/매도 주문 (실제 시세 기준 체결)
- [ ] 보유 종목(포트폴리오)과 평가손익 표시
- [ ] 체결 내역(거래 이력) 저장 — DB 도입
- [ ] 수수료/세금 반영

**학습 목표**
- 웹개발: DB 설계와 ORM, 서버 액션/뮤테이션, 트랜잭션
- 주식: 매수/매도, 평단가, 평가손익/실현손익, 수수료·거래세

---

## M3. 자동 매매 엔진 (가상) ⬜

전략에 따라 자동으로 주문을 내는 엔진을 만든다. 이 프로젝트의 핵심.

- [ ] 매매 전략 정의 인터페이스 (예: 이동평균 교차, RSI)
- [ ] 전략 실행기 — 시세를 보고 자동 매수/매도 판단
- [ ] 스케줄링 (장중 주기 실행)
- [ ] 자동 매매 로그와 알림 표시

**학습 목표**
- 웹개발: 백그라운드 작업/스케줄러, 상태 관리, 이벤트 로그 설계
- 주식: 이동평균선, RSI 등 기술적 지표, 매매 전략의 기본 구조

---

## M4. 백테스팅 & 전략 고도화 ⬜

과거 데이터로 전략을 검증하고 성과를 측정한다.

- [ ] 과거 일봉 데이터 수집/저장
- [ ] 백테스트 실행기 (기간/종목/전략 선택)
- [ ] 성과 지표: 누적 수익률, 최대 낙폭(MDD), 승률
- [ ] 전략 파라미터 튜닝 화면

**학습 목표**
- 웹개발: 대량 데이터 처리, 시각화(수익률 곡선)
- 주식: 백테스팅의 의미와 한계, 수익률/MDD/승률, 과최적화 위험

---

## M5. KIS 모의투자 연동 ⬜

한국투자증권 Open API의 **모의투자** 계좌로 실제 주문 흐름을 연습한다.

- [ ] KIS Open API 계정/앱키 설정 (환경변수 관리)
- [ ] 인증(토큰 발급/갱신) 모듈
- [ ] 모의투자 잔고/주문/체결 조회 연동
- [ ] 가상 매매 엔진을 모의투자 주문으로 연결

**학습 목표**
- 웹개발: OAuth 류 토큰 인증, 시크릿 관리, 외부 API 에러 처리
- 주식: 실제 주문 유형(지정가/시장가), 체결 프로세스, 증거금

---

## M6. 실전 매매 ⬜

실계좌로 전환한다. 안전장치가 최우선.

- [ ] 실계좌 전환 스위치 (모의/실전 명시적 구분)
- [ ] 리스크 관리: 손절 라인, 종목당/일일 투자 한도
- [ ] 모니터링 대시보드와 이상 상황 알림
- [ ] 운영 기록(감사 로그)

**학습 목표**
- 웹개발: 운영 안정성(모니터링/알림), 안전한 배포
- 주식: 리스크 관리 원칙, 슬리피지, 실전과 백테스트의 괴리
