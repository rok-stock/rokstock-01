# 벤치마크와 지수 — "나 잘하고 있는 건가?"의 기준

## 개념

### 지수 (index)

시장 전체의 흐름을 숫자 하나로 요약한 것. **KOSPI 지수**는 유가증권시장 전체 종목의
시가총액을 1980년 기준(=100)과 비교한 값이다. "코스피 2,600"은 1980년보다 시장 전체
가치가 26배라는 뜻. 개별 종목이 아니라 **시장 그 자체의 성적표**다.

### 벤치마크 (benchmark)

내 성과를 판단할 비교 기준. 수익률 +5%는 좋은 걸까? **같은 기간 시장이 +10%였다면**
사실 시장보다 못한 것이다. 그래서 펀드매니저의 성과도 "벤치마크 대비 초과수익"으로
평가한다.

이 게임의 벤치마크 카드는 정확히 이 질문을 던진다:

```
같은 날 1억을 전부 KOSPI 지수에 넣었다면 지금 얼마?
벤치마크 자산 = 1억 × (오늘 지수 ÷ 시작일 지수)
```

### 왜 "시장을 이기기 어렵다"고 할까

- 종목을 고르는 순간 **수수료·세금**이 발생하지만 지수는 가만히 있어도 된다
- 시장 수익의 대부분은 소수의 급등 종목이 만든다 — 그걸 미리 고를 확률은 낮다
- 장기 통계에서 액티브 펀드의 다수가 지수를 밑돈다. 그래서 "지수를 사는"
  **인덱스 투자**(ETF 등)가 분산투자의 기본기로 꼽힌다

이 게임에서 벤치마크에 계속 진다면, 그것 자체가 값진 학습이다 — 실전이었다면
인덱스 ETF가 답이었을 수 있다는 뜻이니까.

### 한계 (정직하게)

- 지수는 **배당 재투자를 반영하지 않는다** (배당 포함은 "총수익지수"가 따로 있다).
  실제 지수 투자는 배당만큼 여기 계산보다 유리하다.
- 게임 시작일이 휴장일이면 직전 거래일 지수를 기준으로 쓴다.
