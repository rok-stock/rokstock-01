# 재무제표 읽기 기초 — 그리고 PER/PBR

## 개념

### 요약 재무제표의 여섯 숫자

| 항목 | 뜻 | 어디서 |
|---|---|---|
| 매출액 | 1년 동안 판 금액 (외형) | 손익계산서 |
| 영업이익 | 매출에서 원가·판관비를 뺀, **본업으로 번 돈** | 손익계산서 |
| 당기순이익 | 이자·세금까지 다 정산한 최종 이익 | 손익계산서 |
| 자산총계 | 회사가 가진 전부 | 재무상태표 |
| 부채총계 | 남의 돈 | 재무상태표 |
| 자본총계 | 자산 − 부채 = **주주의 몫(순자산)** | 재무상태표 |

한 해 숫자보다 **3개년 추세**가 중요하다. 매출은 느는데 영업이익이 줄면 마진이 무너지는
중이고, 순이익만 튀면 일회성 이익(자산 매각 등)일 수 있다.

연결 vs 별도: 자회사를 합친 게 **연결**재무제표다. 이 게임은 연결을 우선 사용한다
(없으면 별도).

### PER — 이익 대비 가격

```
PER = 시가총액 ÷ 당기순이익
```

"지금 버는 속도로 몇 년 벌면 회사값이 되나". PER 10배 = 10년치 이익 가격.
낮으면 싸다고들 하지만, **이익이 줄어들 회사라서 싼** 경우가 흔하다(가치 함정).
적자 기업은 계산 자체가 안 된다.

### PBR — 순자산 대비 가격

```
PBR = 시가총액 ÷ 자본총계
```

1배 미만 = 장부상 순자산보다 싸게 거래된다는 뜻. 다만 장부가치는 공장·재고 기준이라
브랜드·기술 같은 무형 가치를 놓치고, 반대로 안 팔리는 재고가 부풀려 있을 수도 있다.

### 가치평가의 한계 (이 게임의 교육 포인트)

- PER/PBR 은 **비교 지표**다 — 같은 업종끼리, 과거의 자신과 비교할 때 의미가 생긴다
- 분모(이익·자본)는 **과거** 숫자고 주가는 **미래**를 반영한다. 싸 보이는 데는
  대개 이유가 있다
- 그래서 리포트 하단에 "숫자가 싸 보이는 데는 이유가 있을 수 있어요"를 박아뒀다
