# 배당 — 주식이 주는 "월세"

## 개념

**배당**은 회사가 번 이익의 일부를 주주에게 현금(또는 주식)으로 나눠주는 것이다.
주가 상승(시세차익)과 함께 주식 수익의 두 축을 이룬다.

### 꼭 알아야 할 용어

| 용어 | 뜻 |
|---|---|
| 주당배당금 (DPS) | 1주당 받는 현금. 분기 배당 회사는 연 4번 나눠 준다 — 연간 합계로 봐야 한다 |
| **배당수익률** | 연간 주당배당금 ÷ 현재 주가. "주가 대비 몇 %를 현금으로 받나" |
| 배당 기준일 | 이 날 주주명부에 있어야 배당을 받는다 |
| 배당락 | 기준일이 지나 배당받을 권리가 사라진 상태 — 그만큼 주가가 빠지는 게 보통 |
| 배당성향 | 순이익 중 배당으로 주는 비율. 100% 를 넘으면 지속 불가능한 신호 |

### 배당수익률 함정 두 가지

1. **높다고 좋은 게 아니다** — 분자(배당)가 커진 게 아니라 분모(주가)가 폭락해서
   수익률이 높아 보이는 경우가 흔하다. 다음 해 배당이 깎이면 함정이 완성된다.
2. **과거 숫자다** — 이 게임의 배당수익률은 "최근 1년 실제 지급액" 기준이다.
   미래 배당은 회사가 언제든 줄일 수 있다.

### 우선주가 배당에서 나오는 이유

우선주는 의결권 대신 **배당을 조금 더** 받는 주식이다. 그래서 배당 투자자는
같은 회사라도 우선주(예: 삼성전자우)를 선호하기도 한다. 이 게임의 리포트 지표는
보통주 기준이라 우선주 화면에서는 배당수익률을 숨긴다(왜곡 방지).

## 데이터 뒷이야기 (이 프로젝트)

- 금융위 주식배당정보 API 는 **역대 배당 이력 전체**를 준다(삼성전자 170건, 1987년부터!).
  최근 370일의 현금배당만 합산해 "연간 주당배당금"을 만든다 — 분기 배당 대응.
- 이 API 응답에 **액면가**가 함께 들어 있어서, 별도 신청이 필요하던 주식발행정보 API 가
  불필요해졌다. API 문서를 실제로 호출해 보면 명세에 없는 보물이 나오기도 한다.
- 경로 함정: 다른 금융위 API 와 달리 이 서비스만 `…/1160100/service/…` 가 아니라
  `…/1160100/` 바로 아래에 있다.
