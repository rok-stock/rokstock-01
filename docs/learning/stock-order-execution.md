# 주문과 체결 — 그리고 룩어헤드 편향

## 개념

**주문(order)** 과 **체결(execution)** 은 다르다. 주문은 "사고 싶다/팔고 싶다"는 의사표시이고,
체결은 상대방을 만나 실제로 거래가 성립하는 순간이다. 실제 시장에서 주문 유형은 크게:

| 유형 | 뜻 | 체결가 |
|---|---|---|
| 시장가 주문 | "지금 얼마든 사/팔아줘" | 즉시 체결되지만 **가격은 미리 모른다** |
| 지정가 주문 | "이 가격 이하로만 사줘" | 가격은 확정, **체결 여부를 미리 모른다** |
| 종가 체결(MOC) | "장 마감 가격으로 사줘" | 마감 단일가로 체결 |

무엇을 선택하든 **"가격과 체결을 동시에 확정할 수는 없다"** 는 게 시장의 본질이다.

## 룩어헤드 편향 (look-ahead bias)

이 게임의 데이터는 하루 늦게(T+1) 온다. 만약 "최근 종가로 즉시 체결"을 허용하면:

1. 포털 뉴스에서 **오늘** 급등한 종목을 확인한다
2. 게임에서 **어제 종가**로 매수한다
3. 내일 데이터가 갱신되면 무위험 수익 확정

이렇게 "그 시점엔 알 수 없었던 미래 정보"로 과거 가격에 거래하는 오류를
**룩어헤드 편향**이라 한다. 백테스팅(과거 데이터로 전략 검증)에서 가장 흔한 함정이기도
하다 — 예를 들어 "그날 종가가 이동평균을 돌파하면 그날 종가에 매수"하는 백테스트는
종가가 확정되기 전엔 돌파 여부를 알 수 없으므로 성과가 부풀려진다.

## 이 게임의 해법: 다음 거래일 종가 체결

주문 시각 이후 **처음 마감(15:30)되는 거래일의 종가**로 체결한다.

- 주문할 때 체결가를 알 수 없다 → 시장가 주문의 불확실성을 그대로 학습
- 미래 정보로 과거 가격에 살 수 없다 → 치팅 원천 차단
- 단타가 불가능하다 → 기업을 보고 사는 습관이 강제된다

그래서 매수는 수량이 아니라 **금액**으로 주문한다("50만 원어치"). 체결가를 모르는 상태에서
수량을 지정하면 "돈이 모자라는 체결"이 생길 수 있기 때문이다. 체결 시 금액 안에서 살 수 있는
최대 수량을 사고 잔돈은 돌려받는다.
