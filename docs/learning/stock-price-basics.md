# 시세 읽는 법 — 현재가, 등락률, 캔들

관련 마일스톤: M1

## 현재가와 등락

| 용어 | 뜻 |
|---|---|
| **현재가** | 지금 이 순간 마지막으로 체결된 가격 |
| **종가** | 그날 장이 끝날 때의 마지막 체결 가격 |
| **전일 대비** | 전 거래일 종가와 비교한 가격 차이 (예: `-900`) |
| **등락률** | 그 차이를 퍼센트로 (예: `-0.93%`) |
| **거래량** | 그날 사고팔린 주식 수 |

등락률 계산은 단순하다:

```
등락률(%) = (현재가 - 전일 종가) / 전일 종가 × 100
```

거래량이 중요한 이유: 같은 5% 상승이라도 거래량이 평소의 10배면 무언가 사건이 있었다는 뜻이고,
거래량이 평소만 못하면 소수의 거래로 흔들린 값일 수 있다. 가격만 보면 안 되는 이유다.

## 빨강과 파랑 — 한국은 반대다

**한국 증시는 상승이 빨강, 하락이 파랑이다.** 미국은 상승이 초록, 하락이 빨강이라 정반대다.

이 프로젝트는 한국 관례를 따른다. 색은 `src/lib/market/format.ts`의 `changeColorClass()`와
`CANDLE_COLORS` 한 군데에서만 정한다.

색만으로 정보를 전달하면 색각 이상이 있는 사람은 읽을 수 없다. 그래서 등락은 `+`/`-` 부호와
숫자를 항상 같이 보여준다.

## 캔들(봉) 차트

막대 하나가 하루다(일봉). 하나에 네 개의 가격이 들어있어 **OHLC**라고 부른다.

| 약자 | 우리말 | 뜻 |
|---|---|---|
| **O**pen | 시가 | 그날 처음 체결된 가격 |
| **H**igh | 고가 | 그날 가장 높았던 가격 |
| **L**ow | 저가 | 그날 가장 낮았던 가격 |
| **C**lose | 종가 | 그날 마지막 체결 가격 |

```
      │ ← 고가
    ┌─┴─┐
    │   │ ← 몸통: 시가와 종가 사이
    └─┬─┘
      │ ← 저가
```

- **몸통(body)**: 시가와 종가 사이. 종가가 시가보다 높으면 빨강(양봉), 낮으면 파랑(음봉).
- **꼬리(wick)**: 몸통 위아래로 뻗은 선. 장중에 여기까지 갔다가 되돌아왔다는 뜻.

몸통이 짧고 꼬리가 길면 "많이 흔들렸지만 결국 제자리"라는 의미다. 몸통이 길면 방향이 뚜렷했던
날이다.

## 차트를 그릴 때 지킨 것

거래량을 **가격 차트 위에 두 번째 세로축으로 겹쳐 그리지 않았다.** 축이 두 개인 차트는 눈금을
어떻게 잡느냐에 따라 없는 상관관계도 있어 보이게 만든다. 대신 아래쪽 별도 영역(pane)에 그려
가로축(날짜)만 공유하게 했다.

캔들 차트는 canvas로 그려서 화면 낭독기가 읽지 못한다. 그래서 같은 데이터를 "일별 시세 표로
보기"에서 표로도 제공한다.

## 이 프로젝트의 데이터 한계

공공데이터포털 시세는 **T+1**이다. 다음 영업일 오후에 갱신되므로 실시간이 아니다. 화면의
"현재가"는 사실상 가장 최근 영업일의 **종가**다. 실시간에 가까운 시세는 M5에서 KIS API를 붙일 때
다룬다.

자동 매매를 만들 때 이 차이는 중요하다. 일봉만 보고 짜는 전략과 실시간 호가를 보고 짜는 전략은
완전히 다른 물건이다.
