# 로드맵 (마일스톤)

**"하루 늦은 모의주식"** — 공공데이터포털의 일별 시세(T+1 영업일 13시 갱신)를 그대로 게임 규칙으로
삼은 **모바일 모의투자 게임**을 만든다. 로그인 없이 localStorage로 동작하고, 초기 자금 1억 원으로
시작하며, 기업 리포트 등 건전한 투자 개념을 학습 요소로 담는다.

> 2026-08 방향 전환: 원래 이 프로젝트는 자동 매매 프로그램(가상 매매 → KIS 모의투자 → 실전)을
> 목표로 했다. M1까지 진행한 뒤 **게임 중심으로 전면 개편**했다. 기존 자동 매매 로드맵(구 M2~M6)은
> 문서 하단 [장기 아이디어](#장기-아이디어-구-m2m6)에 보존한다.
>
> 상태 표기: ⬜ 예정 / 🟨 진행 중 / ✅ 완료

## G1. 시드 데이터 파이프라인 + 공급자 개편 + ISR ✅

KOSPI 전 종목 데이터를 로컬에서 생성해 커밋하고, 운영 중 API 호출을 최소화하는 기반을 만든다.

- [x] 시드 생성 스크립트 (`scripts/build-seed.ts`) — KOSPI 종목 마스터(+법인등록번호),
      최근 5영업일 전 종목 시세 스냅샷, KOSPI 지수 1년치
- [x] 시드 산출물 커밋 (`src/data/*.json`, 튜플 포맷으로 용량 최적화 — raw 약 300KB)
- [x] 시세 공급자 개편: 전 종목 스냅샷 1회 페치가 단일 진실 공급원, 검색은 시드 로컬(API 0회),
      API 실패 시 시드 fallback
- [x] ISR 적용 (`export const revalidate` + fetch 태그) 및 온디맨드 재검증
      (`/api/revalidate` + Vercel cron, 13시 갱신 직후 반영)
- [x] Vercel 배포 설정 (vercel.json, 환경변수 문서화)

**구현 메모**
- KRX상장종목정보에는 우선주가 없어(831법인 vs 시세 943종목) 시세 스냅샷과 병합하고,
  우선주의 법인등록번호는 보통주에서 유도했다.
- 기업재무·기업기본·배당·발행정보 API는 승인 확인 후 G6에서 연동한다
  (배당·발행은 비상업 용도 사용 — [game-design.md](./game-design.md) 라이선스 절 참조).

**학습 목표**
- 웹개발: ISR(Incremental Static Regeneration), 데이터 캐시와 태그 재검증, cron
- 주식: 종목 마스터, 시가총액/상장주식수, 지수(KOSPI)의 의미

## 장기 아이디어 (구 M2~M6)

게임이 완성된 뒤에 검토할 원래 로드맵의 아이디어들. 게임의 데이터 파이프라인과 도메인 로직
(체결/평가) 위에 얹을 수 있다.

- **자동 매매 엔진 (가상)** — 전략 인터페이스(이동평균 교차, RSI), 전략 실행기, 스케줄링, 매매 로그
- **백테스팅** — 과거 일봉 수집/저장, 백테스트 실행기, 성과 지표(누적 수익률/MDD/승률)
- **KIS 모의투자 연동** — 한국투자증권 Open API 모의투자 계좌, 토큰 인증, 잔고/주문/체결 조회
- **실전 매매** — 실계좌 전환, 리스크 관리(손절 라인/한도), 모니터링·감사 로그
