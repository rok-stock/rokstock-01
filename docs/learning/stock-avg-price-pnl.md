# 평단가와 손익 — 평가손익 vs 실현손익

## 개념

### 평단가 (평균 매입 단가)

같은 종목을 여러 번 나눠 사면 "내 매입 가격"은 하나가 아니다. 그래서 **총 매입금액 ÷ 보유
수량**으로 평균을 낸다:

```
10주를 70,000원에, 10주를 80,000원에 샀다면
평단가 = (700,000 + 800,000) / 20 = 75,000원
```

구현 팁: 평단가를 직접 저장해 두고 매수 때마다 "재계산"하면 반올림 오차가 누적된다.
이 게임은 **원본값(totalCost, 총 매입금액)** 을 함께 저장하고 평단가는 파생값으로 계산한다.
(수수료는 평단가에 포함하지 않는 단순한 규칙을 썼다 — 증권사마다 포함 여부가 다르다)

### 평가손익 vs 실현손익

| | 평가손익 (미실현) | 실현손익 |
|---|---|---|
| 언제 | 보유 중 | **매도 체결 순간** 확정 |
| 계산 | (현재가 − 평단가) × 보유수량 | 매도 정산액 − 매입원가 |
| 성질 | 시세 따라 매일 출렁임 | 다시는 안 바뀜 |

"수익률 +20%"는 팔기 전까지는 **숫자일 뿐**이다. 매도해야 세금·수수료를 뗀 실현손익이
확정된다. 이 게임의 매도 정산:

```
실현손익 = (수량 × 종가) − 수수료 − 농특세 − (수량 × 평단가)
```

일부만 매도하면 남은 수량의 평단가는 그대로 유지되고, 매입원가(totalCost)만 판 만큼
비례해서 줄어든다.

### 왜 구분이 중요한가

- 평가이익은 "아직 시장의 것"이다 — 확정하려면 팔아야 하고, 파는 순간 비용이 든다
- 계좌 화면의 "총 수익률"이 실현+평가를 섞어 보여주면 착시가 생긴다. 이 게임은
  누적 실현손익(realizedPnlTotal)을 별도 필드로 보관해 구분해 보여준다
